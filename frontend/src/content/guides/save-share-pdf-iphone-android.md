## Choose the right action after processing

The finished-file card stays on the page with the exact filename and file size. You can try another saving method without running the PDF tool again.

| Action | What it does | What to check |
| --- | --- | --- |
| Download | Requests a browser download with the displayed filename | Your browser’s download list or Files app |
| Open | Opens a supported PDF, image or plain-text result in another tab | Viewing is not the same as saving |
| Share or save | Sends the actual file to your device’s native share menu, when supported | Choose an app or Save to Files if offered |
| Save as… | Opens a destination picker in supported browsers | The site reports success only after the selected file has been written |
| Rename | Changes the result’s filename without saving it | Choose a saving action after confirming the name |

## Save a PDF on iPhone or iPad

1. Finish your PDF task and wait for the result card.
2. If **Share or save** is available, tap it. Choose **Save to Files** if your device offers that option, select the destination, and complete the device’s save step.
3. If sharing is unavailable, tap **Download**. Check Safari’s download list and the Files app’s Downloads folder. The location depends on your settings.
4. Open the saved copy and check its pages before closing the result tab.

If a PDF opens in a browser viewer, use that viewer’s sharing or saving controls. An embedded browser inside another app can have fewer file options; opening Filozy in Safari may help.

## Save a PDF on Android

1. Tap **Download** on the completed result.
2. Open Chrome’s **Downloads**, or your device’s Files app. Look for the filename displayed by Filozy.
3. To use another destination, try **Share or save** when available and choose an offered app.
4. Confirm the saved file opens correctly. Your browser and destination app control the folder and whether a copy is uploaded to cloud storage.

## Multiple output files and renaming

Split and extraction tasks may create more than one file. The result shows the total count, total size, and numbered file cards. All cards remain expanded on the page rather than inside a small scrolling list.

- **Save all (ZIP)** prepares one archive. Choose **Download all (ZIP)** when it is ready, then extract the archive in your Files app. Packaging does not change the files inside it.
- **Share all** opens your device's share menu when it supports the batch. Otherwise save the ZIP and share it from your Files app. Some devices can share a prepared ZIP directly.
- **Open all** opens one viewer listing every result. Select a file to preview it. Unsupported formats can be downloaded and opened in their own app. This avoids opening a burst of browser tabs.

Each result also keeps its own actions. Rename a file before downloading or sharing it; the extension stays appropriate for the output. Where the rename dialog offers an apply-to-all option, review the numbered filenames before confirming. After renaming, prepare the ZIP again so it includes the new names.

Saving one result does not automatically save every other result. Check the number of output files and keep the page open until you have the copies you need.

## If the save menu disappears or nothing opens

- Returning from a device menu does not delete the result. Look for its card on the same Filozy page and try another action.
- A cancelled share leaves the file available. A completed share request still does not prove another app saved it.
- Check whether a popup blocker prevented Open from creating a tab.
- Large files can exceed a browser’s sharing or memory limits. Try Download, reduce the output size, or use a device with more available memory.
- Do not reload, close the tab, start over or select another input until you have checked your copy. Results are temporary, not an online document account.

## Privacy when sharing

PDF processing takes place on your device. Choosing a share destination is a separate action: that app or cloud provider may receive and keep your completed document under its own policies. Do not share confidential files with an unintended destination.
